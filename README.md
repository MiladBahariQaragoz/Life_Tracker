# Life Tracker

**Live Demo:** [https://life-tracker-six-omega.vercel.app/](https://life-tracker-six-omega.vercel.app/)

Life Tracker is a comprehensive full-stack application built with React, Node.js, and Google Sheets API. It gamifies and tracks your daily productivity, gym progress, and study sessions, enriched with AI coaching capabilities.

## Features
- **Gym & Workouts:** Template creation, exercise tracking, progressive overload analysis, and AI-generated weekly schedules.
- **Study Planner:** Exam tracking, topic mastery goals, and session logging.
- **Task Matrix:** Priority-based task tracking with Google Calendar synchronization.
- **Analytics:** Visualized data including volume progression, productivity heatmaps, and mastery radar charts.
- **AI Coach:** Gemini AI integration providing contextual advice based on your daily data and reported mood.

For detailed architecture and system design, please see [system.md](system.md).
